# 部署

把已验证制品安全发布到明确授权的环境并保留完整记录。

## Inputs

- 可追溯制品
- 目标环境、服务、版本和部署授权

## Work

- 确认目标与权限并完成部署前检查
- 执行部署和健康检查
- 失败时停止扩散并按已确认方案回滚

## Outputs

- 部署或回滚结果
- deploy/log/ 下的完整记录
- status/ 中的环境状态

## Completion

- 目标版本部署结果明确
- 健康检查和关键功能验证完成
- 日志、风险和后续动作已记录

## Safety

风险等级：`critical`。继承 `deploy/safe.json`；对话中新提出的用户安全规则优先于项目总安全规则，项目总安全规则优先于本 Step。

- 每次部署都必须确认环境、服务和版本
- 生产部署与回滚必须获得明确授权
- 部署节点不得修改业务代码
