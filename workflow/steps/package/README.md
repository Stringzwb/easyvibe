# 项目打包

以可重复方式生成来源明确、内容安全、可验证的交付制品。

## Inputs

- 已验证代码和依赖锁定文件
- 版本、构建配置和目标平台

## Work

- 确认版本和来源提交
- 在干净环境执行构建
- 扫描制品、生成清单和校验值

## Outputs

- deploy/artifact/ 下的版本化制品
- 构建清单、哈希和结果记录

## Completion

- 构建成功且可重复
- 制品不含凭证和非必要文件
- 版本、来源和校验值可追溯

## Safety

风险等级：`medium`。继承 `deploy/safe.json`；对话中新提出的用户安全规则优先于项目总安全规则，项目总安全规则优先于本 Step。

- 制品不得包含源码外泄项、凭证或生产配置
- 已有版本制品默认不可覆盖
